# IDS Editor 仕様書

IDS.TXT互換のテキストファイルを編集するためのエディターです。

編集するレコードの仕様については [Specification document for the IDS.TXT file](ids-format.txt) を参照してください。

## インストール

1. Gitリポジトリーをクローンする。

2. リポジトリトップディレクトリーで、依存パッケージをインストールする。

```shell
bun install
```

## エディターの起動

1. Bunを使って、コマンドライン引数に編集したいファイルを指定してサーバーを起動する。

```shell
bun run scripts/ids-editor.ts ids/draft/unicode-17.0.txt
```

2. URLが表示されるので、ブラウザーからアクセスする。

## エディター画面

ブラウザーで開いたエディターには、レコードに次のフィールドが表示されています。

- Unicode符号位置 (read only)
- 文字（拡大表示） (read only)
- IDS文字列とソースタグ（配列）
- コメント

また、レコード一覧として、Unicode符号位置・文字が表示されていて、クリックするとそのレコードの編集に移ることができます。

IDS.TXTのレコードの例：

```
U+5CC0	峀	^⿱山由$(GTKP)	^⿱山田$(J)	*U+5CC0≠U+2B73A;U+5CC0(J)=U+2B73A
```

これは、エディターの内部で、次のデータとして取り扱われます。

```json
{
    "codepoint": "U+5CC0",
    "char": "峀",
    "data": [
        {"ids": "⿱山由", "source": "GTKP"},
        {"ids": "⿱山田", "source": "J"}
    ],
    "comment": "U+5CC0≠U+2B73A;U+5CC0(J)=U+2B73A"
}
```

[JSONスキーマファイル](ids-data.schema.json)

### 入力内容のチェック

IDS文字列とソースタグは、変更時、入力形式にエラーがないかチェックする。

エラーがある場合はわかるように表示する。

### 編集の保存

エディターの保存ボタンを押すと、編集結果がファイルに出力される。
オートセーブにも対応する。
